# Vet Care LTD 🐾

A thoughtful, warm, and responsive veterinary clinic website built for **Vet Care LTD** (Migombani Street, Mikocheni, Dar es Salaam, Tanzania).

## ✨ Features

- **Figma Editorial Design System**: Warm palette (`#FAF8F3` cream, `#14382C` forest green, `#C4643E` terracotta) with Fraunces serif and Plus Jakarta Sans typography.
- **Interactive Services Showcase**:
  - 5 core clinical services with dedicated photographic assets:
    1. *Health & Wellness Exam*
    2. *Vaccines & Parasite Prevention*
    3. *Dental Care & Hygiene*
    4. *Ultrasound & Lab Diagnostics*
    5. *Medicated Pet Grooming*
  - Category filter pills (*Wellness*, *Vaccines*, *Dental*, *Diagnostics*, *Grooming*)
  - Horizontal swipeable / scrollable track with carousel navigation arrows
- **Interactive Service Detail Pop-Up Modal**:
  - Full-resolution photo, clinical overview, pricing (`From TZS ...`), visit duration, and suitability
  - "What's Included in This Visit" checklist
  - Direct WhatsApp consultation link pre-filled with the service name for `+255 713 325 000`
- **Location & Visit Planning**:
  - Embedded interactive Google Maps centered on Migombani Street
  - One-click directions to Vet Care LTD on Google Maps
  - Clinic hours, contact details, and instant WhatsApp chat
- **Frequently Asked Questions (FAQs)**:
  - Interactive accordion addressing walk-ins, vaccination schedules, emergencies, payment methods, and grooming
- **100% Mobile & Cross-Device Responsive**:
  - Ergonomic mobile hero background integration
  - Native touch-swipe scroll snapping
  - Bottom-sheet mobile modal presentation

## 🚀 Running Locally

No dependencies required! Run using any local web server:

```bash
# Using Python
python -m http.server 8088

# Using Node.js npx
npx serve .
```

Open `http://localhost:8088` in your browser.
